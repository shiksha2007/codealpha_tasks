# CodeAlpha_HangmanGame

A simple text-based Hangman game built using Python as part of my CodeAlpha internship.

## Features
- Random word selection from five predefined words
- Guess one letter at a time
- Maximum of six incorrect guesses
- Input validation
- Repeated-guess detection
- Console-based gameplay

## Technologies Used
- Python
- random module
- while loop
- if-else statements
- Strings and lists

## How to Run
1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

   python hangman.py
