
# CodeAlpha_BasicChatbot

A simple rule-based chatbot built using Python as part of my CodeAlpha internship.

## Features
- Responds to greetings
- Answers basic predefined messages
- Provides a help option
- Ends the conversation when the user types bye
- Handles unknown messages with a default reply

## Technologies Used
- Python
- Functions
- if-elif-else statements
- while loop
- User input and output
- Strings

## How to Run
1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

   python chatbot.py
